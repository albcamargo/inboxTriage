Instalacion operador no-autor — README.md

git clone https://github.com/TU_USUARIO/inboxtriage && cd inboxtriage
npm install
cp .env.example .env # pon GOOGLE_CLIENT_ID
cp contexto.example.json contexto.json
npm run qvac:smoke # Scope 1 verde
npm run gmail:auth && npm run gmail:labels
npm run triage:15 # Scope 5 verde >=10 mails
npm run demo:3min # Scope 6 ensayo

Recorte permitido CICLO.md: si no hay token a las 5h, usa npm run gmail:fixtures y sigue con fixtures. Juez ve terminal + Gmail.

Privacidad y no-gos

✔ Cuerpo del mail nunca a OpenAI/Anthropic/Google Generative Language. Verificable con npm run demo:check-cloud
✔ Tokens OAuth solo en disco local, nunca en git. .gitignore + .env.example
✔ Out of Scope: no redacta respuestas, no mira calendario, no RAG, no 4ta categoria
